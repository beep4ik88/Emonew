# Emotoday — бот почасового трекера эмоций

## Что делает
- `/start` — настройка времени подъёма и отбоя
- Каждый час в это окно шлёт вопрос «Что вы сейчас чувствуете?» с 5 кнопками (гнев/страх/грусть/радость/любовь), затем уточняющий выбор
- В час отбоя присылает сводку дня + рекомендацию

## Структура проекта
```
emotoday/
├── main.py           # точка входа
├── config.py         # чтение токена и настроек из .env
├── database.py        # SQLite: пользователи, записи настроения
├── emotions.py         # 5 базовых эмоций + уточнения — правьте здесь
├── keyboards.py         # инлайн-кнопки
├── scheduler.py         # почасовая рассылка
├── summary.py           # сводка дня и рекомендации
├── handlers/
│   ├── start.py         # онбординг (время подъёма/отбоя)
│   └── emotion.py       # обработка выбора эмоции
├── requirements.txt
└── .env                # ваш токен бота (НЕ публикуйте, НЕ заливайте в открытый git)
```

## Деплой на Railway (бесплатно для старта, самый простой вариант)

1. Зарегистрируйтесь на **railway.app** (можно через GitHub)
2. Загрузите эту папку в новый репозиторий на GitHub (или воспользуйтесь Railway CLI — см. ниже)
3. В Railway: **New Project → Deploy from GitHub repo** → выберите репозиторий
4. Во вкладке **Variables** добавьте переменные:
   - `BOT_TOKEN` — токен от BotFather
   - `ANTHROPIC_API_KEY` — ключ для генерации сводки дня через Claude (см. ниже, как получить). Без него бот всё равно работает, но сводка будет по шаблону, а не сгенерированной под конкретный день.
   Файл `.env` в репозиторий заливать не нужно, он для локального теста.
5. Railway автоматически поставит зависимости из `requirements.txt` и запустит `python main.py`
6. Готово — бот работает постоянно, пока проект активен на Railway

### Альтернатива — без GitHub, через Railway CLI
```bash
npm install -g @railway/cli
cd emotoday
railway login
railway init
railway variables set BOT_TOKEN=ваш_токен
railway up
```

## Локальный запуск (для проверки перед деплоем)
```bash
cd emotoday
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
Файл `.env` уже с вашим токеном — бот запустится сразу.

## Как получить ANTHROPIC_API_KEY
1. Зайдите на **console.anthropic.com** и зарегистрируйтесь/войдите
2. В разделе **API Keys** создайте новый ключ
3. Пополните баланс (расход тут копеечный — одна сводка в день на человека, пара центов в месяц на пользователя)
4. Вставьте ключ в переменные окружения (Railway) или в `.env` (для локального теста)

## Что можно донастроить
- **Часы подъёма/отбоя в кнопках** — сейчас выбор 6:00–10:00 и 21:00–01:00 (`keyboards.py`). Если нужен произвольный ввод времени текстом — могу переделать.
- **Эмоции и уточнения** — правятся в `emotions.py`, без изменения остального кода.
- **Рекомендации** — сейчас шаблонные (по 5 сценариям в `summary.py`). Если захотите более живые/персонализированные тексты — можно подключить вызов Claude API вместо шаблонов, понадобится отдельный API-ключ Anthropic.
- **Часовой пояс** — по умолчанию Europe/Moscow, можно сделать настраиваемым при онбординге.

## Важно про безопасность токена
Никогда не публикуйте `BOT_TOKEN` в открытых репозиториях или чатах. Если он уже "засветился" — в @BotFather есть команда `/revoke` для перевыпуска токена.
